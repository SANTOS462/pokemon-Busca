Pesquise aqui!

O aplicativo de busca de Pokémon permite pesquisar Pokémon pelo nome ou número e visualizar informações como imagem, nome e tipo. O projeto utiliza HTML, CSS, JavaScript e uma API para buscar os dados de forma rápida e dinâmica, criando uma experiência simples e interativa para o usuário.
